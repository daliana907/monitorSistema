System Monitor for NVDA

Author: Daliana (based on Resource Monitor by Joseph Lee and contributors) | Version 2.4 | Compatibility: NVDA 2019.3 or later

System Monitor gives you immediate, accessible insights into your computer's hardware, battery, peripherals, and network performance.

Basic Shortcuts (NVDA + Shift + Key)

ShortcutReported Information
NVDA + Shift + EResource summary (RAM usage and overall CPU load)
NVDA + Shift + 1CPU load average and per-core utilization
NVDA + Shift + 2Physical and virtual RAM (used, total, and percentage)
NVDA + Shift + 3Free and total disk space across all drives
NVDA + Shift + 4Wi-Fi network SSID, signal strength, and security
NVDA + Shift + 5CPU clock speed (current GHz, base clock, and turbo status)
NVDA + Shift + 6Windows edition, version, and architecture
NVDA + Shift + 7System uptime
NVDA + Shift + 8Dedicated GPU status (memory usage, core load, and temperature)

Advanced Diagnostics (NVDA + Shift + Control + Number)

Press once to hear the report spoken. Press twice quickly to copy the result directly to your clipboard.

ShortcutDiagnostic Tool
NVDA + Shift + Control + 1Drive health (S.M.A.R.T.), temperature, and SSD wear percentage
NVDA + Shift + Control + 2Top resource-consuming processes (highest CPU and RAM usage)
NVDA + Shift + Control + 3Real-time internet speed test (ping, download, and upload speeds)
NVDA + Shift + Control + 4Advanced laptop battery health, runtime, and design capacity wear
NVDA + Shift + Control + 5Connected Bluetooth devices and audio peripheral battery levels

Automated Background Alerts

Configurable under NVDA Menu > Preferences > Settings > System Monitor:

  • High CPU or GPU temperatures.
  • Low laptop battery or battery full notification.
  • Low battery alerts for connected Bluetooth audio devices.
  • Wi-Fi disconnect and signal strength change notifications.
  • Critical wear threshold alerts for SSDs.

NVDA Tools Menu

You can access the add-on from NVDA > Tools > System Monitor:

  • Settings...: Opens the System Monitor configuration panel directly.
  • Documentation: Opens this user guide.
