System Monitor

Wersion: 2.3  )|  Author: Daliana  )|  Compatibility: NVDA 2019.3 or later

This add-on provides accessible real-time information about RAM usage, CPU load, CPU core metrics, clock frequency/turbo boost, disk space, battery status and health, Wi-Fi connection and signal strength, internet speed, Windows build information, system uptime, and multi-vendor GPU/VRAM performance.

Origin and Acknowledgements: This add-on is an extended fork built upon the foundation and inspiration of the classic Resource Monitor add-on by Joseph Lee and contributors for the NVDA community. It expands upon the original design by integrating complementary capabilities (multi-vendor GPU/VRMM monitoring for AMD, Intel, and NVIDIA; S.M.A.R.T. disk health analysis; battery reporting for classic Bluetooth audio and BLE peripherals; internet speed testing; and configurable background event alerts) into a unified, all-in-one accessible hardware suite.
